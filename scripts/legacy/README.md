# Скрипты версии ВКР

`extract_hno3_cities.py` — исходный скрипт из ВКР в неизменном виде (сохранён для истории).
Извлекает концентрацию HNO₃ из файлов TCR-2 (NetCDF) в точках городов и сохраняет в Excel.

Известные ошибки этого скрипта (исправлены в `scripts/process_tcr2.py`):

- год вычисляется по номеру файла (`year = 2010 + file_index`), а не из метаданных — сдвиг на 1 год;
- пропущенные значения (masked) записываются как `0.0`, а не как «нет данных»;
- значения делятся на 1000 (ppt → ppb), но в интерфейсе подписаны как ppm;
- пути к файлам жёстко заданы (`C:/`), список файлов собирается по шаблону имени.

`migrate_mls_json.py` — одноразовый перевод JSON-файлов CO, H₂O и O₃ из версии ВКР
в новый формат (исходные NetCDF для них не сохранились). Уже выполнен, повторный запуск ничего не меняет.
